
# Riley – Systems Planner (CLI)

This is a VS Code–ready Python project for the **Riley** agent.

Riley:
- Takes a DiscoveryReport (usually generated by your Jordan agent).
- Produces a structured ProjectSpec + WorkPackages for all your specialist agents.

## Setup

1. Unzip this folder somewhere on your machine.
2. Open the folder in VS Code.
3. Make sure you have Python 3.9+ installed.
4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Set your OpenAI API key as an environment variable:

   **macOS / Linux:**
   ```bash
   export OPENAI_API_KEY="your_key_here"
   ```

   **Windows (PowerShell):**
   ```powershell
   setx OPENAI_API_KEY "your_key_here"
   ```

6. (Optional) Place `DiscoveryReport.md` in the same folder if you already have Jordan's output.

## Run

```bash
python riley_agent.py
```

Riley will:
- Ask for the project type.
- Ask whether to load `DiscoveryReport.md` or let you paste it.
- Call the OpenAI API and print a full ProjectSpec + WorkPackages.
- Optionally save the result to `ProjectSpec.md`.
