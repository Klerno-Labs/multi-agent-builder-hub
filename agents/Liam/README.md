
# Liam – Frontend Engineer Agent (CLI)

This agent reads:
- ProjectSpec.md (from Riley)
- DesignSpec.md (from Ava)
- Optional frontend work packages

Then generates frontend code + structure using React/Next.js + TypeScript + Tailwind.

## Run:

```
pip install -r requirements.txt
export OPENAI_API_KEY="your_key"
python liam_agent.py
```
